# Quran Companion Pro

১/ কুরআন শরীফ দেখে পড়বে সাথে, দেশ অনুযায়ী তরজমা, 

২/ কুরআন শরীফ পড়বে সাথে সাথে লেখা উঠবে ভুল হলে ভুলটা আর সঠিক টা এক সাথে লেখা উঠবে, পড়ার সময় কোনো একটা যায়গা চাপ দিয়ে রাখবে কেমন যেন রেকর্ড

৩/ কিছু কারীর তেলাওয়াত থাকবে ওই গুলো এক আয়াত পড়তে পরে যে ব্যবহার করবে তাকে পড়ার সময় দিবে সাথে সাথে ভুল হলে ওই আয়াত রিপিট করবে এবং ভুল হওয়ার যায়গা টা লাল বা কোনো কালার দিয়ে মার্ক করা উঠবে,
