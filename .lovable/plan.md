

# রিডিং ভিউ — Imdadia Hafezi Quran PDF অনুযায়ী রিডিজাইন

## PDF থেকে যা দেখা যাচ্ছে (পেজ ৪-৫ রেফারেন্স)

1. **টেক্সট অনেক বড়** — প্রতিটি লাইন পুরো প্রস্থ জুড়ে, বোল্ড ক্যালিগ্রাফিক ফন্ট
2. **প্রতি পৃষ্ঠায় ঠিক ১৫ লাইন** টেক্সট, প্রতিটি লাইন সমান উচ্চতা
3. **কর্নার অর্নামেন্ট** — ফ্রেমের চার কোণায় ডেকোরেটিভ কার্ল/মোটিফ
4. **হেডার** (ফ্রেমের বাইরে): বাম = সূরার নাম + নম্বর, মাঝখান = পৃষ্ঠা নম্বর, ডান = জুয মার্কার
5. **ফুটার**: منزل ١
6. **সূরা শুরুর পেজ**: উপরে সূরার নাম/আয়াত সংখ্যা/রুকু সংখ্যা, তারপর বিসমিল্লাহ, তারপর কম লাইন
7. **আয়াত নম্বর** — ছোট বৃত্তাকার চিহ্ন (৫) ইনলাইনে

## বর্তমান সমস্যা

- টেক্সট সাইজ ছোট (`text-[20px]`) — PDF-এ অনেক বড়
- `min-h-[520px]` ফিক্সড — কন্টেন্টের সাথে মেলে না
- কর্নার অর্নামেন্ট নেই
- লাইন স্পেসিং (`leading-[2.5]`) কম — PDF-এ প্রতিটি লাইন আরো স্পেসড
- টেক্সট fully justified নয়

## পরিবর্তন — `src/components/quran/ReadingView.tsx`

### ১. টেক্সট সাইজ ও স্টাইলিং বড় করা
- ফন্ট সাইজ: `text-[26px] md:text-[30px]` (বর্তমান `20px/24px` থেকে বাড়ানো)
- লাইন হাইট: `leading-[2.8] md:leading-[3]`
- `font-bold` যোগ — PDF-এর মতো বোল্ড ক্যালিগ্রাফি
- `text-justify` + `text-align-last: center` for better justification

### ২. কর্নার অর্নামেন্ট যোগ
- CSS `::before`/`::after` বা absolute positioned ছোট ডেকোরেটিভ SVG/unicode কার্ল চার কোণায়
- Unicode ornament characters: `❁` বা `﴾` স্টাইলের কর্নার পিস

### ৩. ফ্রেম বর্ডার আরো prominent
- বাইরের বর্ডার মোটা করা (`border-[4px]`)
- ভেতরের বর্ডার আরো দৃশ্যমান (`border-[2.5px]`)

### ৪. `CHARS_PER_LINE` অ্যাডজাস্ট
- বড় ফন্টে কম ক্যারেক্টার ফিট হবে — `CHARS_PER_LINE` কে `45` থেকে `35`-এ কমানো
- `types.ts`-এ আপডেট

### ৫. min-height রিমুভ
- `min-h-[520px]` সরিয়ে content-driven height ব্যবহার

### ৬. আয়াত নম্বর স্টাইল
- সামান্য বড় (`text-[14px]`) + বোল্ড + গোল্ড/গ্রিন কালার

## ফাইল পরিবর্তন
1. `src/components/quran/ReadingView.tsx` — টেক্সট সাইজ, কর্নার অর্নামেন্ট, ফ্রেম স্টাইল
2. `src/components/quran/types.ts` — `CHARS_PER_LINE = 35`
